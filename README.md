# 古树守望 · Four Realms

原创奇幻 2.5D 单机英雄塔防。四个入口依次来袭，四族高塔自由混搭，玩家操控一名无敌英雄守护中央古树。

## 游戏内容

- 一张固定道路、32 个固定塔位的 3D 等距地图
- 简单 / 普通 / 困难三档完整 20 波流程
- 王国箭塔、森灵树塔、霜魂冰塔、荒原战鼓，均可升至 5 级
- 三名 25 级英雄，含主动、被动、终极技能与属性加点
- 精英波、分难度 Boss 机制、古树修复、存档恢复与最佳记录
- iPhone 横屏优先，支持 PWA 主屏幕安装和首次加载后离线启动

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产验证：

```bash
npm run lint
npm run test:engine
npm run simulate
npm run audit:scenarios
npm run build
npm run start
```

## 操作

- 备战阶段点击发光塔位建塔；战斗中可升级，备战阶段可出售与修复古树。
- 左侧摇杆移动英雄；桌面端也可使用 WASD / 方向键。
- 英雄普攻自动锁敌，右侧技能按钮自动选择最近合法目标。
- 每波入口和敌人类型会提前显示；塔自动攻击距离古树最近的合法敌人。

## 数据与隐私

游戏无账号、无广告、无内购、无联网对战。存档、设置与成绩只保存在当前浏览器的本地存储中。
